# aeon.science

The public site of aeon.science: an instrument that sits on a liquid-handling robot, keeps cells alive in standard plates, and images them while the robot changes their conditions.

One page, in English (`/`) and Japanese (`/ja`). The Japanese is written as native copy, not translated; every visible string lives in `src/lib/i18n/{en,ja}.ts`. A first visit from a Japanese-first browser is sent to `/ja`; the EN/JA switch sets a cookie that wins thereafter.

The mark is a long exposure of one Lorenz trajectory, generated by `scripts/gen-mark.py` and drawn live by `src/lib/images/AeonMarkLive.svelte`. The instrument is `src/lib/components/diagrams/InstrumentSection.svelte`: one patch of a plate, pinned while the page scrolls. The camera descends on the robot's clock (from above, where changes come from, down through the plate to where we watch); the scroll can only hurry it, a mouse over the stage turns the view about each station, and a press on a well puts a change into it; hold longer and it is stronger. The robot runs its own protocol once the reader has arrived, and the map of what answered stays for the rest of the page.

## Develop

```sh
npm install
npm run dev        # http://localhost:5173
npm run build
npm run check
node --test --test-isolation=none tests/th/*.gate.mjs   # the design and copy gates
```

## Deploy

Production (aeon.science) is the Cloudflare Pages project `aeon-website`, built from `main` on push. Staging is the direct-upload project `aeon-website-staging` (`bash scripts/deploy-staging.sh`, which needs a local `.env`). Preview hosts answer with `X-Robots-Tag: noindex`.
