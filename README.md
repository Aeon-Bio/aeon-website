# aeon.science

The public site of aeon.science: an instrument that sits on a liquid-handling robot, keeps cells alive in standard plates, and images them while the robot changes their conditions.

One page, in English (`/`) and Japanese (`/ja`). The Japanese is written as native copy, not translated; every visible string lives in `src/lib/i18n/{en,ja}.ts`. A first visit from a Japanese-first browser is sent to `/ja`; the EN/JA switch sets a cookie that wins thereafter.

The mark is a long exposure of one Lorenz trajectory, generated by `scripts/gen-mark.py` and drawn live by `src/lib/images/AeonMarkLive.svelte`. Below it is the bench (`src/lib/components/diagrams/InstrumentSection.svelte`): one patch of a plate seen from over it, where changes come from. The instrument does the experiment in the open: as you arrive it puts one change into one well, the cells answer in place beside the wells not touched, and once that answer has settled it puts the next change into the next well of the row by itself, stronger if few cells answered and weaker if many. Tap or click a well and one more change goes in, at the same strength every change starts at; the instrument follows it the same way. The keyboard gets the same thing as a button after the plate. The record (`Record.svelte`, data in `bench.js`) draws the changed wells as themselves, in order, with the bead that went into each one under it; it is drawn small beside the plate and large under the readout. The view never moves.

Product truth is in `PRODUCT.md`, the visual system in `DESIGN.md`, the home page's direction contract in `.impeccable/briefs/home.md`.

## Develop

```sh
npm install
npm run dev        # http://localhost:5173
npm run build
npm run check
node --test --test-isolation=none tests/th/*.gate.mjs   # the design and copy gates
```

## Deploy

Production (aeon.science) is the Cloudflare Pages project `aeon-website`, built from `main` on push. Staging is the direct-upload project `aeon-website-staging` (`bash scripts/deploy-staging.sh`, which needs a local `.env`). Preview hosts answer with `X-Robots-Tag: noindex`.
